# MES CORE V27 Enterprise

## Overview

MES CORE V27 is a complete Manufacturing Execution System designed for refrigerator production lines.

Main Modules:

- Authentication
- Dashboard
- Production
- Quality
- Reports
- Users
- Settings
- Analytics
- Backup
- Export
- Synchronization
- Offline Mode
- Firebase Firestore
- Progressive Web App

## Installation

1. Clone the project.

2. Configure Firebase.

3. Update:

```
js/firebase.js
```

4. Enable:

- Authentication
- Firestore
- Storage

5. Open:

```
index.html
```

or deploy using Firebase Hosting.
